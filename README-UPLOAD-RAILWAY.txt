راهنمای رفع خطای دیپلوی Railway — نسخهٔ ۶ (v1.1.0)
=====================================================

❌ خطایی که می‌دادید:
   npm error Invalid: lock file's lucide-react-native@0.475.0 does not
   satisfy lucide-react-native@0.520.0
   → یعنی روی گیت‌هاب شما package.json نسخهٔ جدید (۰.۵۲۰) آپلود شده بود
     ولی package-lock.json قدیمی (۰.۴۷۵) مانده بود؛ npm ci با این ناهماهنگی
     قطعاً شکست می‌خورد. ضمناً Node ی که Railway گرفته بود (20.18.1) از حد
     مجاز پکیج‌ها (20.19.4+) پایین‌تر بود.

✅ راه‌حل — فقط ۵ فایل زیر را در ریشهٔ ریپوی گیت‌هاب آپلود کنید
   (همه «معمولی» هستند؛ هیچ فایل مخفی‌ای لازم نیست):

   1) package.json          ← جایگزین قبلی
   2) package-lock.json     ← جایگزین قبلی  ← مهم‌ترین فایل! حتماً آپلود شود
   3) nixpacks.toml         ← جایگزین قبلی (Node 22 + نصب با npm install)
   4) railway.json          ← جایگزین قبلی
   5) server.js             ← جایگزین قبلی (endpoint جدید /ip-check اضافه شد)

   ⚠️ اگر حتی یک فایل جا بماند — به‌خصوص package-lock.json — باز هم خطا
      می‌گیرید. برای آپلود: در صفحهٔ ریپو → Add file → Upload existing files
      → هر ۵ فایل را یکجا بکشید و رها کنید → Commit changes.
      (فایل هم‌نام، خودکار جایگزین قبلی می‌شود.)

✅ بعد از آپلود:
   - Railway خودش دوباره Deploy می‌شود (یا: Railway → Deployments → Deploy).
   - در لاگ باید ببینید:
       node -v  →  v22.x        (دیگر EBADENGINE نداریم)
       npm install --legacy-peer-deps --include=dev
     سپس expo export و در آخر:  Build Successful

🧯 حتی اگر باز هم فایلی گم شود؟
   - با این package-lock هماهنگ، حتی `npm ci` پیش‌فرضِ Nixpacks هم بدون
     خطا پاس می‌شود (تست شده)؛ پس خیالتان راحت.
   - nixpacks.toml اگر آپلود شود، به‌جای npm ci از
     `npm install --legacy-peer-deps --include=dev` استفاده می‌کند که
     قفلِ ناهماهنگ را هم خودش ترمیم می‌کند — دو لایه محافظت.

🆕 این نسخهٔ APK (v1.1.0) چه چیزهایی جدید دارد؟
   - رفع زوم آیکون: لوگوی کامل و بدون برش بعد از نصب روی صفحهٔ گوشی
   - رفع آیکون تب «تنظیمات» (قبلاً مثلث/نام خام route نشان می‌داد)
   - بخش «بررسی IP و فیلترشکن» در تنظیمات: چک خودکار هر ۳ ثانیه، نمایش
     IP + کشور + وضعیت؛ با IP تحریمی (ایران/کوبا/کرهٔ شمالی/سوریه) دادهٔ
     کیف پول بلاکچین و صرافی‌های خارجی ارسال نمی‌شود و پیغام روشن‌کردن
     فیلترشکن نمایش داده می‌شود؛ بقیهٔ بخش‌ها با IP ایران هم کار می‌کنند
   - رفع باگ «افزودن کیف پول اتفاقی نمی‌افتاد» (مودال خطاها بی‌صدا حذف
     می‌شد) + دکمهٔ کپی آدرس هر کیف (کادر آدرس کامل + آدرس‌های اختصاصی
     هر شبکه در جزئیات هر کیف)
   - رنگ‌بندی قیمت لحظه‌ای: بازار جهانی طلا باز → انس/دلار/طلای ۱۸ با
     کادر و عدد سبز؛ بازار بسته → انس قرمز + خط وضعیت «بازار جهانی طلا»

نسخهٔ کامل ریپو (همهٔ فایل‌ها) هم در asset-management-github.zip موجود است.
