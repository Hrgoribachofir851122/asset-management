# 👛 اپ مستقل «مدیریت دارایی» — نسخه 1.3.0

این پروژه، **اپ مستقل مدیریت دارایی** است که از بخش «مدیریت دارایی» اپ پامپی
(pampay-coin-alert نسخه **1.5.12**) ساخته شده — با **لوگوی جدید** و یک
**AppContext سبک‌شده**، دقیقاً مطابق راهنمای بسته `pampi-asset-management`.

- ✅ تمام فایل‌های هسته (۳۱ فایل) **byte-for-byte** از پامپی کپی شده‌اند
  (`sha256` در لاگ ساخت تأیید شده) — حتی یک کاراکتر تغییر نکرده است.
- ✅ لوگوی جدید در `assets/images/` (icon، adaptive-icon، splash-icon، favicon).
- ✅ Context سبک‌شده: فقط همان چیزی که wallet لازم دارد (`settings.refreshInterval` + تم).
- ✅ TypeScript کل پروژه با `tsc --noEmit` بدون خطا کامپایل می‌شود.

### 🔖 انتشار نسخه جدید (برای بروزرسانی خودکار)
1. در ریپوی GitHub به **Releases → Draft a new release** بروید.
2. Tag را به شکل `v1.3.1` بزنید (باید از نسخهٔ نصب‌شدهٔ کاربر بزرگ‌تر باشد).
3. در توضیحات Release، تغییرات را فارسی بنویسید — همین متن در بنر بالای صفحهٔ کاربر نمایش داده می‌شود.
4. فایل APK را به Release پیوست کنید (پسوند `.apk`).
5. تمام! برنامهٔ کاربران به‌صورت خودکار (بدون زدن هیچ دکمه‌ای) پیام نسخهٔ جدید را بالای صفحه نشان می‌دهد و با دکمهٔ دانلود مستقیم به فایل APK می‌رسد. ریپو هم داخل برنامه تنظیم شده؛ اگر خواستید ریپوی دیگری بگذارید فقط `DEFAULT_GITHUB_REPO` در `constants/appInfo.ts` را عوض کنید.
6. چک بروزرسانی از طریق سرور (asset-management1.up.railway.app) انجام می‌شود و از ایران هم بدون فیلترشکن جواب می‌دهد.

## 📱 داخل اپ چیست؟

نوار پایین (RTL) دو تب دارد — **راست: «مدیریت دارایی»، چپ: «تنظیمات»** —
و اپ همیشه روی «مدیریت دارایی» باز می‌شود.

### تب «مدیریت دارایی» (کد دست‌نخورده پامپی)
چهار تب داخلی، همان که در پامپی می‌دیدید:

| تب | توضیح |
|---|---|
| 💠 **ارز دیجیتال** | افزودن صرافی‌ها با API (بایننس، بیت‌پرپ با ایمیل+کد یکبارمصرف، بای‌بیت، اوکی‌ایکس، LBank با RSA و…)؛ موجودی کامل Overview: اسپات + ارن + فاندینگ + فیوچرز + آلفا؛ PnL هر دارایی و PnL کلی صرافی |
| 🏦 **دارایی ریالی و فلزات** | قیمت لحظه‌ای تومان (طلای ۱۸/۲۴، نقره، سکه امامی/بهار/نیم/ربع، دلار، تتر) از TGJU؛ ورود دارایی فیزیکی؛ خلاصه ارز دیجیتال/کیف بلاکچین/تتر کل؛ کارت PnL امروز/۷/۳۰/۹۰/۱۸۰ روزه (پیش‌فرض: امروز) |
| 🥇 **پیش‌بینی طلا** | تحلیل و پیش‌بینی شمش خام ۹۹۵ در بورس کالا (IME) با فاصله اطمینان |
| ⛓ **کیف پول بلاکچین** | فقط آدرس عمومی (بدون کلید خصوصی) روی ۵۱ شبکه؛ PnL سه‌سطحی با تایم‌فریم ۷/۳۰/۹۰/۱۸۰ روز؛ رفرش و ویرایش هر کیف |

### تب «تنظیمات» (بازسازی‌شده از نقل‌های settings-extract)
- ⏱️ **بازه بروزرسانی خودکار** — ۳ ثانیه تا ۳۰ دقیقه (عیناً گزینه‌های پامپی)
- 🌙 **ظاهر برنامه** — تم روشن/تیره، بلافاصله روی کل اپ اعمال و ذخیره می‌شود
- ❓ **راهنما** — سه راهنمای مدیریت دارایی (عیناً متن‌های پامپی)
- ℹ️ **درباره** — نام، نسخه و توضیح اپ

## 🚀 اجرا و ساخت

### اجرای آزمایشی (Expo Go)
```bash
npm install
npx expo start
```
با Expo Go روی گوشی اسکن کنید. (بعضی درخواست‌های شبکه در Expo Go محدودیت CORS وب دارند؛ تست نهایی با بیلد APK توصیه می‌شود.)

### ساخت APK
```bash
# روش ۱ — لوکال (مثل پامپی):
npx expo prebuild -p android
cd android && ./gradlew assembleRelease
# خروجی: android/app/build/outputs/apk/release/app-release.apk

# روش ۲ — EAS:
npm i -g eas-cli
eas build -p android --profile preview
```

> 💡 اگر پکیج/باندل جدید می‌خواهید، `android.package` و `ios.bundleIdentifier`
> را در `app.json` عوض کنید. `projectId` قدیمی پامپی عمداً حذف شده؛ اولین
> `eas build` خودش پروژه جدید می‌سازد.
